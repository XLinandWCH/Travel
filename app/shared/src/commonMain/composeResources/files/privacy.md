# 文旅Agent 隐私政策（暂行版）

**版本：V0.1（试行）｜发布日期：2026年10月24日｜有效期至正式版隐私政策发布之日**

## 一、引言与适用范围

1.1 《文旅Agent》（暂定名，以下简称“本服务”）由【运营主体名称】（以下简称“我们”）运营。我们深知个人信息对您的重要性，将按照《中华人民共和国个人信息保护法》（以下简称《个人信息保护法》）《中华人民共和国网络安全法》《网络数据安全管理条例》等法律法规，以合法、正当、必要和诚信原则处理您的个人信息。

1.2 本政策适用于我们向您提供文旅智能问答服务过程中，对您个人信息的收集、存储、使用、加工、传输、提供、公开、删除等处理活动。请您在使用本服务前仔细阅读并充分理解本政策，重点内容我们已**加粗**提示。

## 二、我们收集的个人信息

为遵守“收集个人信息应当限于实现处理目的的最小范围，不得过度收集”的要求，本暂行版期间，我们仅收集以下信息：

| **信息类别** | **具体字段** | **处理目的**             | **保存期限**     |
| -------- | -------- | -------------------- | ------------ |
| 账号信息     | 手机号      | 注册、登录、身份验证、账号安全及必要通知 | 账号存续期间；注销后删除 |
| 账号信息     | 电子邮箱     | 账号验证、找回密码、服务通知       | 同上           |
| 个人基本资料   | 年龄、性别    | 用于改善问答服务的相关性与体验      | 同上           |

2.2 **服务统计数据**：我们为评估产品运营情况（如留存率、日活跃用户数等）会处理使用统计信息。此类信息仅在去标识化或匿名化后用于统计分析，**匿名化处理后的信息不属于个人信息**，我们不会将其用于识别您的个人身份。

2.3 **AI 聊天记录的本地存储**：

* 您与本服务 AI 的聊天记录默认通过本地数据库（SQLite）存储在**您自己的设备本地，不上传云端**；
* 仅当您主动使用跨平台/跨设备数据迁移功能时，聊天数据才会在完成迁移所必需的最短时间内临时上传云端；
* **迁移完成后，我们将在 7 个工作日内删除云端迁移的 AI 聊天数据**，不会留存备份（技术上无法立即删除的残余备份，我们将停止除存储和安全保护之外的处理）。

2.4 我们不会主动收集您的位置、行踪轨迹、生物识别、金融账户等敏感个人信息。如您在对话中自行输入此类信息，请注意相关内容由 AI 处理生成回复，建议避免输入不必要的个人敏感信息。若后续因功能扩展需要收集敏感个人信息，我们将依《个人信息保护法》取得您的**单独同意**，并制定专门的处理规则后再行更新本政策。

## 三、我们如何使用个人信息

3.1 我们将所收集的信息用于：注册登录与账号管理、提供文旅问答服务、保障服务安全稳定运行、开展匿名化统计分析以改进产品。

3.2 处理目的、方式、种类发生变更的，我们将重新取得您的同意。

3.3 **我们不会将您的个人信息用于自动化推荐、个性化广告推送**；后续如需开展，将依法提供拒绝选项并另行告知。

## 四、信息的共享、转移与公开

4.1 **共享**：本暂行版期间，我们不向任何第三方共享您的个人信息，除非：（1）取得您的单独同意；（2）为履行法定职责或义务所必需（如配合有权机关依法调取）。涉及不满十四周岁未成年人信息的，还须取得其父母或其他监护人的同意。

4.2 **转移**：如您使用跨设备迁移功能，聊天数据仅在实现迁移目的所必需的最小范围内传输；除本政策第 2.3 条所述情形外，我们不会向境外提供您的个人信息。

4.3 **公开**：除取得您单独同意或法律另有规定外，我们不会公开您的个人信息。

## 五、存储与安全

5.1 我们在中华人民共和国境内收集和产生的个人信息将存储在境内，不向境外提供。

5.2 我们采取加密存储、访问权限最小化、去标识化等安全技术和管理措施，防止未经授权的访问及信息泄露、篡改、丢失。

5.3 发生或可能发生个人信息泄露、篡改、丢失的，我们将立即采取补救措施，按规定通知您并向主管部门报告。

5.4 您的个人信息保存期限为实现处理目的所必要的最短时间；期限届满或您注销账号、撤回同意后，我们将主动删除或匿名化处理（法律法规另有规定的除外）。

## 六、您的权利

依据《个人信息保护法》第四十四条至第五十条，您有权：

* **查阅、复制**您的个人信息；
* **更正、补充**不准确或不完整的信息；
* **删除**您的个人信息（如撤回同意、注销账号、保存期限届满等情形）；
* **撤回同意**，我们提供便捷的撤回方式，撤回不影响撤回前已进行的处理效力；
* **注销账号**，注销后我们将删除您的个人信息；
* 要求我们对个人信息处理规则进行**解释说明**。

行权方式：通过【App 内“设置—账号设置”—对应入口】或发送邮件至【xlinandwch\@outlook.com】提出，我们将在【15】个工作日内响应；拒绝您的请求的，将向您说明理由。

## 七、未成年人保护

7.1 本服务暂不面向未满十四周岁的未成年人提供服务。如您为未成年人的监护人，发现被监护人在未取得您同意的情况下使用本服务或提供了个人信息，请通过【联系方式】联系我们，我们将及时删除相关信息。

7.2 如后续开放未成年人使用，我们将制定专门的未成年人个人信息处理规则，并取得其父母或其他监护人的同意后方可处理其个人信息。

## 八、政策的更新

8.1 本政策为暂行版。未经您同意，我们不会减少本政策中您依本政策所应享有的权利。处理目的、方式、种类发生变更的，我们将以显著方式公告并重新取得您的同意。

8.2 我们将本政策公开于【App 内“设置—关于—隐私政策”】，便于您查阅和保存。
